## ADDED Requirements

### Requirement: Verification source and date for each tool

The site SHALL show, for each tool, the source its information was verified against and the date of that check.

#### Scenario: Viewing a tool

- **WHEN** a reader views a tool
- **THEN** the site shows the source that tool's information was verified against and the date it was checked

### Requirement: Reach the verification source

The site SHALL present a verification source as a link when that source is published at a web address.

#### Scenario: A source published on the web

- **WHEN** a reader selects a verification source published on the web
- **THEN** the site opens that source

### Requirement: Verification dates when comparing tools

The site SHALL show each tool's verification date when tools are shown together.

#### Scenario: Comparing tools

- **WHEN** a reader compares tools
- **THEN** the site shows the verification date for each tool
